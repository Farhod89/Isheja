# Иш режа — топшириқлар иловаси

Фарғона вилояти МвМТБ бошқармасининг 2026-йил 2-октябрь, 01-19/6429-сон хати
(Октябрь ойи вазифалари) асосида, Ёзёвон тумани учун тайёрланган.

## Иловада нима бор
- **Ойлар карточкалари** — ҳозирча фақат Октябрь тўлдирилган, қолган ойлар
  "Тез кунда" деб кўринади. Кейинги ойлар учун ҳам шу хатдаги бандларни
  юбора олсангиз, `data.js` файлига худди шундай қўшиб бераман.
- **Октябрь → 16 та банд** — ҳар бири хатдаги матн билан тўлиқ мос.
- Ҳар бир банд босилганда:
  - **Word/Excel керак бўлганлар** (1,2,4,5,6,8,9,10,11,12,13,14,15,16-бандлар)
    — тайёр шаблон файл (`templates/` папкасида) тахминий рақамлар билан
    юкланади. Шаблондаги `[__ ]` белгили жойларни ҳақиқий маълумотлар билan
    тўлдирасиз.
  - **3-банд (фотоҳисобот, PowerPoint)** — 3 хил слайд услуби (Яшил/Кўк/Оддий)
    дан танлаб, расмларни юклаб, тўғридан-тўғри шу ерда PowerPoint слайдини
    яратиб юклаб олиш мумкин. "Барча мактабларга тарқатиш" тугмаси эса
    мактабларга юбориладиган алоҳида ҳавола (`school-form.html`) беради —
    мактаблар ўзлари расм юклаб, ўз слайдини яратиб олишади.
  - **7-банд** — Ёзёвонга тегишли эмаслиги алоҳида белгиланган (чунки унда
    фақат бошқа 5 та туман мактаблари номма-ном кўрсатилган).

## Ўрнатиш (GitHub Pages)
1. Янги репозиторий яратинг (масалан `ishreja`).
2. Шу папкадаги **барча файл ва папкаларни** (index.html, data.js,
   slidegen.js, school-form.html, manifest.json, service-worker.js,
   icon-192.png, icon-512.png, templates/) юкланг.
3. Settings → Pages → Source: main branch → Save.
4. Чиққан havola (масалан `https://username.github.io/ishreja/`) орқали
   иловани очинг, телефонингизга "Уй экранига қўшиш" орқали ўрнатиб олинг.

## Мактабларга тарқатиладиган ҳавола
3-банд ичидаги "Барча мактабларга тарқатиш" тугмаси сизга шундай кўринишдаги
ҳавола беради:
```
https://username.github.io/ishreja/school-form.html?template=green
```
Шуни барча мактабларга (Telegram гуруҳи ва ҳ.к. орқали) юборинг — улар
ўзлари расм юклаб, слайдни яратиб, сизга PowerPoint файлини қайтариб
юборишади.

## Кейинги ойлар учун
Ҳар ойнинг расмий хатини (PDF/Word) менга юборсангиз, худди шу тартибда
(карточка → банд рўйхати → шаблон/слайд) қўшиб бераман — `data.js` ва
`templates/` папкасига янги ойга мос файллар қўшилади, бошқа ҳеч нарса
ўзгартирилмайди.

## Эслатма
- Барча Word/Excel шаблонлардаги рақамлар **тахминий** — сиз бажариш
  давомида ҳақиқий маълумотлар билан алмаштирасиз.
- PowerPoint слайд генератори (`slidegen.js`) интернет орқали
  `pptxgenjs` кутубхонасини юклайди (CDN), шунинг учун биринчи ишлатишда
  интернет уланиши керак.
